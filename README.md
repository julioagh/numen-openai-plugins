# Numen OpenAI Plugins

Plugins de Numen Coaching & Consulting para el ecosistema de OpenAI (ChatGPT y Codex).

Cada plugin vive en `plugins/<nombre>/` y es autocontenido:

- `plugin/`: paquete que se sube al portal de OpenAI (manifiesto, Skill, `mcp.json`, recursos).
- `server/`: servidor MCP remoto del plugin (si lo tiene).
- `docs/`: documentación técnica.
